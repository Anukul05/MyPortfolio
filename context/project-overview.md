# Project Overview

## Project Name
**Anukul Prajapati — Interactive Developer Portfolio & AI Assistant**

---

## Overview
This application is a modern, high-performance web portfolio designed to showcase the professional capabilities, enterprise engineering background, and AI integration expertise of Anukul Prajapati, a Full-Stack Java & AI Developer. Built for tech recruiters, hiring managers, and prospective clients, the platform moves beyond a traditional static resume by offering interactive project demonstrations, system architecture breakdowns, and an embedded custom AI Assistant trained on Anukul's professional experience to answer technical and background queries in real time.

---

## Goals
1. **Highlight Enterprise & AI Expertise:** Effectively present full-stack capabilities combining robust backend Java engineering with modern AI workflows.
2. **Drive Recruiter Engagement:** Increase visitor engagement time by providing an interactive AI Assistant that answers resume and experience questions instantly.
3. **Optimized Performance:** Achieve a Lighthouse score of ≥95 across Performance, Accessibility, Best Practices, and SEO.

## Core User Flow
1. **Landing & Orientation:** The user arrives at the Hero section, immediately understanding Anukul's core value proposition (Full-Stack Java & AI Engineering).
2. **Interactive Exploration:** The user navigates through the interactive Tech Stack Grid and Projects Showcase to view live project demos, system architecture diagrams, and GitHub repositories.
3. **AI Assistant Engagement:** The user opens the floating AI Chat Assistant to ask custom questions (e.g., *"What is Anukul's experience with Spring Boot and microservices?"* or *"Summarize his recent AI projects"*).

## Features

### 1. Hero & Branding Section
* High-impact intro headline, core value proposition, and quick links to Resume, GitHub, LinkedIn, and Contacts.
* Dynamic status badge highlighting current availability for roles or consulting.

### 2. Interactive Projects & Systems Showcase
* Grid layout displaying featured projects with filter tags (Java, Spring Boot, React, AI Agents,).
* Detailed modal view for featured projects including system architecture diagrams, tech stack tags, key metrics, and live demo/repo links.

### 3. Interactive AI Resume Assistant
* Embedded chatbot drawer allowing natural language querying about Anukul's experience, skill set, and project history.
* Pre-set prompt chips (e.g., *"Tell me about your Java background"*, *"What AI frameworks do you use?"*) for frictionless interaction.

### 4. Technical Stack & Experience Timeline
* Categorized breakdown of backend (Java, Spring Boot, REST APIs), frontend (React, Tailwind CSS), and AI/Tooling capabilities.
* Chronological experience timeline detailing past contributions, impact metrics, and project outcomes.

### 5. Contact & Connect Section
* Contact form with client-side validation and direct email, phone, WhatsApp, GitHub, and LinkedIn links. Until a backend contact endpoint is configured, form submissions open a prefilled email draft for the visitor to send.
* Quick copy buttons for email address and social links.

---

## Scope

### In Scope
* Responsive Single-Page Application (SPA) layout with smooth section scrolling and dark-mode styling.
* Interactive Projects Grid with architecture diagram previews.
* Client-side AI Chatbot interface integrated with a secure backend endpoint for handling query responses.
* Validated Contact Form; automated backend email delivery requires a configured Spring Boot contact endpoint.
* Production deployment on Vercel with custom domain and SSL configuration.

### Out of Scope
* Multi-user user account creation, signup, or login system.
* Paid blogging engine or CMS administration portal (content is managed statically via clean specs/JSON data files).
* E-commerce functionality or payment gateway processing.

---

## Success Criteria
1. **Functional AI Assistant:** A site visitor can ask a question about Anukul's background in the chat widget and receive an accurate, context-aware answer within 3 seconds.
2. **Project Inspection:** A site visitor can filter projects by technology (e.g., "Java") and open a project details modal showing system architecture and source code links.
3. **Form Delivery:** A contact form submission successfully validates inputs, delivers an email notification to Anukul, and shows a confirmed success state to the user.
